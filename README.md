## 在 GitHub Pages 上線

1. 把資料夾裡的檔案上傳到 GitHub 儲存庫。
2. Settings → Pages，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`。
3. 網址是 `https://<帳號>.github.io/<儲存庫名稱>/`，首頁 `index.html` 會列出所有測驗，並顯示每份的作答狀態（作答中／已交卷）。

## 新增測驗

1. 把新的測驗 .html 放進同一個資料夾。
2. 打開 `index.html`，複製一個 `<a class="c">` 區塊，改編號、名稱、連結，`data-key` 和 `data-n` 要和新測驗一致，就會出現在首頁。
